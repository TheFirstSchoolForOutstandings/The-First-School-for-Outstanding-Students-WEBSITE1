# First School for High Achievers in Latakia - Website Files

## كيفية التشغيل (How to Run)
1. قم بفك ضغط الملف.
2. **خطوة هامة جداً:** انسخ صورة الشعار الرسمية الخاصة بالمدرسة وتأكد من تسميتها `logo.jpg` وضعها داخل المجلد الرئيسي (نفس المجلد الذي يحتوي على ملف `index.html`).
3. افتح ملف `index.html` في أي متصفح ويب حديث (Google Chrome, Edge, Safari).
4. المشروع يعمل محلياً بالكامل (Static HTML/CSS/JS) ولا يحتاج إلى بيئة Node.js أو سيرفر للتشغيل، بفضل استخدام بيئة Tailwind عبر CDN.

## الهيكلية (Structure)
- `index.html`: الصفحة الرئيسية (تصميم متكامل حسب المتطلبات).
- `contact.html`: صفحة التواصل مع نموذج مراسلات تفاعلي.
- باقي الصفحات: قوالب (Templates) جاهزة ومرتبطة بقائمة التنقل بانتظار المحتوى النهائي.
- `css/style.css`: التنسيقات الإضافية والـ Animations (مثل الشريط الإخباري).
- `js/main.js`: تفاعلات الموقع (القائمة الجانبية للموبايل، التبويبات Tabs، الخ).

## ميزات التصميم (Design Features)
- استخدام دقيق لألوان الهوية البصرية المأخوذة من الشعار.
- خط عربي أكاديمي (Cairo) وخط إنكليزي (Inter).
- متجاوب 100% مع شاشات الجوال والتابلت (Mobile-First / Fully Responsive).
- قائمة مسطحة (Flat Navigation) بدون قوائم منسدلة (No Dropdowns) كما طُلب.
